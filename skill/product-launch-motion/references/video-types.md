# Video types

Every type is built entirely in code. Lengths are typical; beat times scale to the chosen length. The example ID matches the example videos in the repo README.

| ID | Type | Best for | Length | Needs | Difficulty |
|---|---|---|---|---|---|
| T01 | Teaser / Countdown | pre-launch, waitlist, launch-week day 0 | 6–40 s | logo, date, a few UI fragments | 2 |
| T02 | Kinetic-Type Announcement | big news with little UI: new model, rename, pricing, vision | 15–60 s | logo, copy | 1–2 |
| T03 | UI-Motion Hero Reveal | major launch or big feature with visible UI | 30–90 s | product screens (rebuilt) | 3–4 |
| T04 | Feature Drop / Changelog | small feature, weekly changelog, in-app "what's new" | 5–30 s | one UI flow | 1–2 |
| T05 | Release Roundup | quarterly or post-event "everything we shipped" | 30–120 s | 4–10 feature screens | 2–3 |
| T06 | Before / After | AI, automation, speed, simplification | 15–45 s | old way + new way + metric | 2 |
| T07 | Problem → Solution | new product or category, audience unaware of the pain | 30–90 s | copy, icons, UI | 2–3 |
| T08 | Use-Case Montage | horizontal products, AI assistants, many roles | 30–75 s | 3–6 short UI flows | 3 |
| T09 | Integration / Partnership | new integration, marketplace listing, co-launch | 10–40 s | both logos (with permission), one cross-product flow | 1–2 |
| T10 | Metric / Milestone | users, funding, anniversary, year in review | 10–60 s | the real numbers | 1–2 |
| S | Launch-Week Series | 5 launches in 5 days | package | one template, a color per day | 2–3 |

## Beat templates

**T01 Teaser (30 s):**
- 0–3 s: black, tension.
- 3–15 s: 4–6 cropped dark UI fragments, 1–2 s each, cutting faster.
- 15–22 s: kinetic tagline, 2–4 words, one word per beat.
- 22–27 s: silence, then the logo lands on the drop.
- 27–30 s: date or "Coming soon" + URL.

Never show the whole UI.

**T02 Kinetic type (40 s):**
- 0–4 s: hook, 1–3 words per beat.
- 4–14 s: the old world or the problem (3 lines).
- 14–18 s: pivot ("So we built…").
- 18–30 s: product name + 3 capability words, optional UI flashes.
- 30–36 s: key line.
- 36–40 s: logo + CTA.

Huge cropped type, background flips on hard cuts, words on the beat grid.

**T03 UI hero (60 s):**
- 0–5 s: hook over blurred UI.
- 5–10 s: title card.
- 10–45 s: 3 moments of 8–10 s each: a label (2–4 words), a push-in, one action completes, the result highlights.
- 45–52 s: pull back to the whole product or a wall of outputs.
- 52–60 s: tagline + logo + "Available today".

Dark or light, with a 3D tilt and slow drift, a macro push-in on the key button, cursor, spotlight.

**T04 Feature drop (10–20 s):**
- Start mid-action with a 3–5 word caption.
- Show the one interaction, slightly slowed down, with cursor highlight and zoom.
- End on the output + "Now in [Product]".

No intro.

**T05 Roundup (60 s, 6 features):**
- 0–4 s: "[Quarter] — everything new".
- Then 6 blocks of 8 s: number card (01/06) → 5 s of UI → one-line benefit.
- Last 8 s: bento recap grid + logo.

Cut on the bar.

**T06 Before/After (30 s):**
- 0–12 s: "Before", desaturated friction montage (tabs, copy-paste, timer).
- 12–14 s: wipe or slider.
- 14–24 s: "After", the same task in 1–2 actions.
- 24–27 s: metric (label it illustrative unless the user gave a real one).
- 27–30 s: CTA.

**T07 Problem → Solution (60 s):**
- 0–5 s: the pain as a question.
- 5–18 s: 2–3 symptoms (icons, UI chaos).
- 18–22 s: turn ("Meet X").
- 22–45 s: the solution in 3 UI beats.
- 45–53 s: proof (only if real).
- 53–60 s: CTA.

**T08 Use-case montage (45 s):**
- 0–4 s: "One [product]. Every [job]."
- Then 4–5 vignettes of 6–8 s, each: role label → typed prompt → result card, one color per role.
- Fast recap grid.
- Logo + CTA.

**T09 Integration (25 s):**
- 0–4 s: logos enter from opposite sides, "×" lockup.
- 4–7 s: one-line value.
- 7–20 s: action in A, result in B.
- 20–25 s: "Available today" + setup hint + URL.

**T10 Milestone (30 s):**
- 0–3 s: "Today we crossed…"
- 3–10 s: count-up that lands on the drop.
- 10–22 s: 3 sub-stats or a timeline.
- 22–27 s: thank you.
- 27–30 s: logo + what's next.

**S Launch week:**
- Teaser before the week.
- Days 1–5: the same bumper template ("Day N / 5", feature name, date, mini UI), with a fixed color per day.
- Recap ("Five launches. One week.") as a bento grid.

One music motif across all of it.

## Decision matrix

**Launch size → primary type (secondary):**

| Launch size | Primary | Secondary |
|---|---|---|
| Major launch | T03 | T07 for a new category; T01 before launch; T02 for 15 s cutdowns |
| Big feature | T03 short | T06 for AI or speed; T02 when there is little UI |
| Small feature | T04 | |
| Changelog | T04 | T05 monthly |
| Teaser | T01 | |
| Launch week | S | |
| Integration | T09 | |
| Milestone or funding | T10 | |

**Product → re-rank:**
- AI product: T06, T08, T02.
- Dev tool: T04, T03 dark, S.
- B2B SaaS: T03, T06, T09.
- Consumer app: T08, T01, T02, T06.

**Assets → feasibility:**
- Logo + copy only: T01, T02, T09, T10.
- With product screens: every type.

**Personality → style:**

| Personality | Style |
|---|---|
| Minimal or precise | dark UI, glow, slow eased camera, ambient electronic |
| Friendly | bright flat color, bouncy easing, upbeat |
| Bold | stomp type, high contrast, fast cuts |
| Premium | slow, negative space, tonal music |
| Technical or trustworthy | grid, mono labels, measured pacing |

**Recommend 2–3 options**, lowest difficulty first among those that fit the launch size, each with a one-line reason.
