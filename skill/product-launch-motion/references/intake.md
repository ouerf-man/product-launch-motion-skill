# Intake

Ask in one compact message. Draft options from what you already read on the user's site.

## Product + launch
- **Product:** what it does, for whom (ICP), category, what it replaces.
- **Feature:** name, what is new exactly, the pain it removes, up to 3 benefits.
- **Launch size:** major · big feature · small feature · changelog · teaser · launch week · integration · milestone.
- **Message:** the one line a viewer must remember. Offer 2–3 drafts.
- **Proof:** real metric, quote or customer logo, each with a source and permission. If there is none, show no stats.
- **Availability:** GA / beta / plan, date. **CTA:** text + URL.
- **Platform(s)** → format + length (see `platform-specs.md`).
- **Voice-over:** yes / no. If yes, the language + an ElevenLabs key.
- **Music:** a licensed file or link from the user, or none.
- **Product access:** a URL to open in Chrome (user logged in), or screenshots.

## Brand checklist (collect once per brand)

| Area | What to collect |
|---|---|
| Foundation | mission, values, positioning, audience |
| Voice | 4 sliders: formal↔casual, serious↔funny, respectful↔irreverent, matter-of-fact↔enthusiastic. Plus "X, not Y" pairs and words to avoid |
| Color | hex + role (canvas, ink, primary, accents) + usage ratio, light/dark |
| Type | display + body font files, weights, tracking |
| Logo | SVG (light/dark), clear space, approved reveal, forbidden treatments |
| Motion | easing personality (precise vs bouncy), speed |
| Visual style | icons, shapes, illustration, signature motifs |
| UI | product URL / UI kit / Figma / screenshots |
| Claims | approved stats, quotes, logos |

Good sources, in order:
1. The brand's UI kit or design tokens (CSS variables, Figma).
2. The live website: computed styles, `@font-face`, logo SVG in the HTML.
3. The product app itself.

## Minimum brief gate (do not storyboard without it)
- **Brand:** logo, 2+ colors with roles, 1 font, a tone description.
- **Launch:** feature name, value prop, pain, up to 3 benefits, CTA, availability, platform, product visuals (access or at least 3 screens).

Missing brand data → use neutral defaults and say so. Missing product facts → ask; never invent them.
